

# AI-Powered Pitch Refinement Agent — Landing Page

A premium, dark-themed SaaS landing page designed to feel like a real startup product page — calm, smart, and high-end.

---

## 🎨 Design System
- **Theme**: Dark modern with deep navy/indigo backgrounds
- **Palette**: Blue → Purple → Indigo gradients with soft gold accents — no greens, no dull grays
- **Effects**: Glassmorphism cards, soft glowing shadows, blur overlays
- **Typography**: Clean, elegant hierarchy with generous spacing
- **Animations**: Smooth fade-ins on scroll, hover glows, micro-interactions throughout

---

## 🧭 Floating Pill Navbar
- Centered, pill-shaped navigation bar floating above the hero with top margin
- Semi-transparent glass background with blur and soft shadow
- **Left**: Logo + "Pitch Agent" name
- **Center**: Home · About · How It Works · Features · Contact (smooth scroll links)
- **Right**: "Get Started" gradient button (blue-to-purple)
- Sticky on scroll with a subtle shrink animation

---

## 🏠 Hero Section
- Two-column layout
- **Left**: Bold headline *"Turn Your Ideas into Winning Pitches"*, supporting subtext, and two CTA buttons — "Generate Pitch" (gradient) and "View Demo" (outline/glass)
- **Right**: Abstract animated gradient orbs/shapes that evoke AI intelligence
- Subtle floating animation on the visual element

---

## ℹ️ About Section
- Clean card-based layout with icons
- Explains the problem (students struggle to present ideas) and the solution (AI structures ideas into strong pitches)
- 2–3 glass-styled cards with icons and short text blocks
- Fade-in animation on scroll

---

## ⚙️ How It Works
- Horizontal 4-step flow with connecting lines/arrows
- Steps: **Enter Idea** → **Enable Pitch Mode** → **AI Generates Draft** → **Present Confidently**
- Each step is a numbered glass card with icon and label
- Cards animate in sequentially on scroll
- Responsive: stacks vertically on mobile

---

## ✨ Features Grid
- 6 glowing glass cards in a responsive grid (3×2 on desktop, stacked on mobile)
- Features: AI Pitch Generator · Pitch Mode Toggle · Structured Draft Output · Web-Enhanced Context · Instant Results · Clean Formatting
- Each card has an icon, title, and short description
- Subtle glow border effect on hover

---

## 🚀 CTA Section
- Full-width section with premium gradient background (blue → purple → indigo)
- Centered text: *"Great Ideas Deserve Great Presentation"*
- Large "Start Now" button with glow effect
- Soft radial light effects in background

---

## 📌 Footer
- Minimal dark footer
- Logo + product name on left
- Navigation links in center
- Contact info and social media icons on right
- Subtle top border with gradient accent

---

## 📱 Responsive Design
- Fully responsive across desktop, tablet, and mobile
- Navbar collapses to hamburger menu on mobile
- All sections gracefully reflow to single-column layouts
